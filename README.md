# Credit Risk Assessment Using Machine Learning

## Project Overview
This project focuses on predicting loan default risk using machine learning classification algorithms. It explores applicant and loan-related data to identify patterns associated with credit risk and evaluates models for their ability to distinguish between default and non-default cases.

## Objectives
- Analyze and preprocess credit risk data.
- Build and compare machine learning classification models.
- Handle class imbalance during model training.
- Evaluate model performance using multiple classification metrics.
- Apply hyperparameter tuning and probability calibration.
- Interpret model predictions using SHAP explainability.

## Technologies Used
- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
- **Machine Learning:** Scikit-learn, XGBoost
- **Explainable AI:** SHAP
- **Environment:** Jupyter Notebook

## Workflow
1. Data exploration and visualization
2. Data cleaning and preprocessing
3. Feature preparation and train-test splitting
4. Model development using Logistic Regression and XGBoost
5. Class imbalance handling
6. Cross-validation and hyperparameter tuning
7. Model evaluation and probability calibration
8. Threshold analysis and error evaluation
9. Model interpretation using SHAP

## Model Evaluation
The project evaluates model performance using:
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC

These metrics provide different perspectives on classification performance, particularly when default and non-default cases are imbalanced.

## Explainability
SHAP (SHapley Additive exPlanations) is used to understand how input features contribute to model predictions and to improve the interpretability of the credit risk assessment process.
